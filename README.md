# 곤충 표본 라벨 시스템 — 설치 순서

파일 세 개로 돌아갑니다. `index.html`이 앱 전체이고, 나머지는 자료입니다.

```
insect-labels/            ← 공개 저장소 (GitHub Pages)
  index.html
  data/checklist.jsonl    ← 국가생물종목록. 공개 자료라 여기 둡니다

insect-collection-data/   ← 비공개 저장소
  data/specimens.jsonl
  data/sites.jsonl
  data/containers.jsonl
```

종목록을 비공개 저장소에 두지 않는 이유는 두 가지입니다. 공개된 정부 자료라 숨길 이유가 없고,
9MB가 넘어서 GitHub API의 1MB 인라인 한도에 걸립니다. 공개 저장소에 두면 앱이 토큰 없이 바로 읽습니다.

### 두 가지 구성 — 공개 셸 또는 전부 비공개

**A안 · 공개 셸 + GitHub Pages** — `insect-labels`(Public)에 앱과 종목록, `insect-collection-data`(Private)에 표본 자료.
URL 하나로 어디서나 열립니다. `index.html`에는 표본 자료가 한 줄도 없고 토큰도 각자 브라우저에만 저장되므로
공개되는 것은 화면 코드뿐입니다(`noindex` 처리됨).

**B안 · 둘 다 Private** — Pages 없이 씁니다. 앱은 `index.html` 파일을 각 PC에 한 번씩 내려받아
더블클릭으로 열고(비공개 저장소 페이지에서 내려받으면 됨 — 회사 PC도 github.com 로그인으로 가능),
표본 자료는 똑같이 GitHub API로 읽고 커밋하므로 **동기화는 A안과 동일하게 유지됩니다.**
종목록(`checklist.jsonl`)도 비공개 저장소 `data/`에 넣어두면 GitHub에서 불러오기 때 함께 받아져
브라우저에 캐시됩니다. 치르는 값은 "URL 하나로 접속"이 안 되고, 앱을 갱신할 때 각 PC에서 파일을
다시 받아야 한다는 것뿐입니다.

참고: 유료(GitHub Pro)로 비공개 저장소에 Pages를 걸어도 **Pages 사이트 자체는 공개**입니다
(접근 제한 Pages는 Enterprise 전용). 그러니 "완전 비공개"가 목표라면 B안이 정답입니다.

## 1. 지금 당장 써보기 — 저장소 없이

1. `index.html`을 크롬으로 엽니다.
2. **설정** 탭에서 `specimens.jsonl`, `sites.jsonl`, `checklist.jsonl`을 각각 열어 불러옵니다.
3. 씁니다. **저장** 버튼을 누르면 GitHub 설정이 없을 때 파일로 내려받습니다.

이 상태로도 라벨 출력까지 전부 됩니다. 다만 기기 간 동기화는 안 되니 확인용으로만 쓰십시오.

## 2. 저장소 만들기

GitHub에 로그인해 저장소 두 개를 만듭니다.

| 저장소 | 공개 여부 | 넣을 것 |
|---|---|---|
| `insect-labels` | Public (A안) — B안이면 생략 | `index.html`, `data/checklist.jsonl` |
| `insect-collection-data` | **Private** | `data/specimens.jsonl`, `data/sites.jsonl`, `data/containers.jsonl` (+B안이면 `checklist.jsonl`, `index.html`도 여기에) |

`insect-labels` 저장소에서 **Settings → Pages → Source: Deploy from a branch → main / (root)** 로 설정합니다.
몇 분 뒤 `https://<사용자명>.github.io/insect-labels/` 로 열립니다.

## 3. 토큰 발급

GitHub **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**

| 항목 | 값 |
|---|---|
| Repository access | Only select repositories → `insect-collection-data` |
| Permissions → Contents | **Read and write** |
| Expiration | 1년 정도 |

회사 PC용으로 하나 더 발급하되 Contents를 **Read-only** 로 줍니다. 실수로 데이터를 건드릴 수 없습니다.

## 4. 앱에 연결

Pages 주소를 열고 **설정** 탭에 넣습니다.

- 사용자: GitHub 사용자명
- 비공개 저장소: `insect-collection-data`
- 브랜치: `main`
- 토큰: 위에서 만든 것
- 토큰 보관: 개인 기기는 *이 브라우저에 저장*, **회사 PC는 반드시 *창 닫으면 삭제***

**GitHub에서 불러오기**를 누르면 연결됩니다. 이후로는 네 기기 모두 같은 주소만 열면 됩니다.

## 인쇄

**출력** 탭에서 범위나 조건으로 대기열을 채우고 인쇄합니다.

처음 한 번은 **눈금자 페이지**를 켜서 1페이지만 뽑고, 100mm 막대를 자로 재어 실측값을 입력하십시오.
인쇄 대화상자에서 **배율 100%**(용지에 맞춤 아님), 머리글·바닥글 끄기.

**모든 표본이 같은 규격입니다** — 보존 형태와 상관없이 한 표본 = 두 장 세트(채집면 + 동정면).
액침도 같은 세트를 두 장 다 tube에 넣습니다.

| | 크기 | A4 한 장 |
|---|---|---|
| 라벨 1장 | 20.00 × 11.43mm | — |
| 한 세트 (채집면 + 동정면) | 20.00 × 22.86mm | 가로 9 × 세로 12 = **108세트** |

한 장에 무엇이 찍히는지:

| 채집면 | 동정면 |
|---|---|
| `KOREA` · 시·도 약호 · 채집번호 | 국명 |
| 영문 채집지 | 학명 + 성별·개체수 (+ 후보 표시) |
| 채집일 (로마 숫자 월) | `Det. 이름` (+ 기관명) |
| 경도 · 위도 (소수점 6자리) | |
| `Coll. 이름` | |

국명이 없는 표본은 그 칸을 학명이 물려받아 세로 가운데에 놓입니다 — 반쪽이 비어 보이지 않습니다.
tube에 여러 마리가 들어 있으면 학명 뒤에 `♂ 5` 처럼 개체수가 붙습니다.
보관 박스·칸은 라벨에 찍지 않습니다(박스를 보면 알 수 있고, 옮기면 바뀌는 값이라서) —
필요하시면 넣어 드리겠습니다.

**미리보기 배율** — 라벨이 작아 화면에서 확인이 어려우므로 미리보기 위에 배율 막대를 두었습니다.
`−` / `＋`, **화면 맞춤**, **실제 크기** 버튼이 있고, 미리보기 위에 마우스를 올리고 **휠만 굴리면** 25%–600%로
확대·축소됩니다. 화면에서만 커질 뿐 **인쇄 크기는 달라지지 않습니다**(300%로 키워 둔 채 인쇄해도
20.00 × 11.43mm 로 나가는 것을 확인했습니다).

### 라벨의 시·도 표기

라벨 머리줄은 `KOREA  CN  JH000001` 처럼 두 자 약호로 찍힙니다.

| | | | | | | | |
|---|---|---|---|---|---|---|---|
| 경기 GG | 강원 GW | 충북 CB | 충남 CN | 전북 JB | 전남 JN | 경북 GB | 경남 GN |
| 제주 JJ | 서울 SL | 인천 IC | 세종 SJ | 대전 DJ | 광주 GJ | 대구 DG | 울산 US |
| 부산 BS | | | | | | | |

"충청북도", "강원특별자치도" 처럼 길게 적혀 있어도 같은 약호로 바뀝니다. 표에 없는 표기는
로마자 앞 두 글자를 씁니다. 표본입력의 채집지점 밑에 `라벨 CB …` 로 미리 보여 줍니다.

기관명은 **설정**에서 넣으면 동정면 오른쪽 아래에 찍힙니다(비우면 미표시).

## 보관함 — 액침은 칸까지, 건조는 상자까지

| 종류 | 번호 | 위치 기록 | 화면 |
|---|---|---|---|
| **격자형** (액침 EP tube 박스) | `WET-0001`… 자동 부여 (4자리) | 칸 `A1` – `I9` (9×9 고정) | 9×9 격자에서 칸을 눌러 지정·조회 |
| **상자형** (건조 표본상자·슬라이드함) | `DRY-0001`… 자동 부여 (4자리) | 없음 — 상자 번호만 | 상자를 고르면 표본이 바로 나열 |

**보관함은 따로 등록하지 않습니다.** 표본입력에서 박스 번호만 적으면 자동으로 생기고
보관함 탭에 바로 나타납니다. 숫자만 쳐도 됩니다 — 액침 상태에서 `1`을 치면 `WET-01`,
건조 상태에서 `3`을 치면 `DRY-03`으로 맞춰집니다. 기존 박스는 입력칸에서 자동완성으로 뜹니다.

액침은 칸을 `a3`, `b2`처럼 직접 입력해도 되고(소문자 자동 대문자화, 사용 중인 칸은 저장 시 차단)
미니 9×9 격자를 클릭해도 됩니다. 건조는 분류군 순으로 꽂혀 있어 상자 번호만 기록합니다.
생식기 슬라이드는 별도 보존형태가 아니라 실험 항목입니다 — 본체 표본과 함께 보관하므로
"해부 · 생식기 슬라이드" 체크로 기록합니다.

**보관함입력** 탭에서 박스를 미리 만들거나 각 박스의 이름·**보관위치**·비고를 표에서 바로 고칠 수 있고,
**보관함** 탭은 조회 전용입니다 — 액침/건조를 고르고 박스 숫자만 치면(1 → WET-0001) 그 박스의
격자와 **종 구성 요약**(종별 표본 수·개체수 합)이 뜹니다.

**중요 — 기록과 저장은 다릅니다.** "기록"은 화면(메모리)에 반영하는 것이고, 위 검정 헤더의
**저장** 버튼을 눌러야 GitHub에 커밋(또는 로컬 파일로 다운로드)됩니다. 저장을 잊고 닫아도
브라우저에 임시 초안이 남아 다음에 열 때 복원을 제안하지만, 임시 초안은 그 브라우저에만 있으니
작업이 끝나면 꼭 저장을 누르십시오(저장 버튼이 초록으로 깜빡이는 동안은 미저장 상태).

## 개체 꺼내기 — 분리와 전환

편집 화면 ③보관의 **꺼내기 / 전환** 버튼으로 열립니다. 두 모드가 있습니다.

- **분리 (새 번호)** — 여러 개체 중 일부를 꺼낼 때. 성별·보존(건조/새 tube)·해부·DNA를 지정해 꺼내면
  새 번호가 붙고(항상 **지금까지 쓴 가장 큰 번호 + 1** — JH001000까지 쓴 뒤 몇 년 만에 분리해도 JH001001),
  parent 표시로 원 번호와 이어지며 **원 tube 개체수가 그만큼 줄어듭니다**(1개체 분리 = 원본 −1).
- **전환 (번호 유지)** — 같은 개체를 통째로 액침 ↔ 건조로 옮길 때. 번호는 개체의 신원이므로 그대로 두고
  보존 형태와 박스만 바뀝니다. **1개체 표본을 꺼내 건조로 만드는 경우가 바로 이것**입니다 —
  1개체일 때는 분리가 잠기고 전환이 기본으로 열립니다. 건조 표본도 똑같이 쓸 수 있습니다.

**생식기를 따로 두는 경우** — ④실험에서 해부를 체크하면 "생식기 보관"이 나타납니다.
본체와 함께(기본)거나, **별도 보관**을 고르고 tube·슬라이드함 박스와 칸을 적으면
그 박스의 보관함 화면에 "생식기 부속"으로 표시되고 격자 칸에도 잡힙니다.
예: 1개체 액침 → 전환으로 본체는 건조 DRY-0002, 해부 체크 + 생식기 별도 보관 WET-0009 B2, DNA 체크 —
한 개체의 몸·생식기·실험이 전부 한 번호로 추적됩니다.

목록에서 표본을 지우려면 체크하고 **선택 삭제** — 경고 배너에서 "정말 삭제"를 한 번 더 눌러야 실행됩니다.

## 대량 시료 — 한 종 수백 개체는 이렇게

원칙은 하나입니다. **채집번호 = 운명을 같이하는 단위.** 같은 보존·같은 실험·같은 보관이면 몇백 개체라도
한 번호로 묶고, 처리가 갈라지는 순간 분리해 새 번호를 줍니다. 분리된 번호는 `parent` 표시로 원 번호와
이어지므로 계보가 끊기지 않습니다.

예 — 별매미충 200개체 (♂5 · ♀195), 수컷 4개체는 액침으로 생식기·DNA, 1개체는 건조로 생식기:

| 단계 | 하는 일 | 결과 |
|---|---|---|
| 1 | 성별이 다르니 두 건으로 입력 (저장 후 이어서) | `JH000101` ♀195 액침 · `JH000102` ♂5 액침 |
| 2 | ♂ tube 열고 **개체 분리** — 1개체 · 건조 · 해부 체크 | `JH000103` ♂1 건조 (해부), tube 잔량 4 |
| 3-가 | 남은 4♂가 통으로 같은 처리면 | `JH000102` 에 해부·DNA 체크만 |
| 3-나 | 슬라이드·추출물을 개체별로 추적하려면 **개체 분리** — 4개체 · 액침 · 해부+DNA 체크 | `JH000104`–`107` 각 ♂1, 번호별 추적 |

개체 분리 창에서 **성별·보존 형태(건조/새 tube)·실험(해부·DNA)** 을 함께 지정할 수 있어서
2·3단계가 각각 클릭 몇 번입니다. 생식기 슬라이드는 본체와 같은 번호를 쓰고(별도 번호 없음),
DNA 추출물 번호는 실험 비고에 적으면 목록에서 태그에 마우스를 올렸을 때 보입니다.

## 표본목록 — 페이지 · 바로가기 · 툴팁

- 목록은 **25 · 50 · 100개씩** 페이지로 나뉘어 나옵니다(선택은 기억됨). 넘치면 아래에 페이지 버튼이 생기고,
  맨 위 체크박스는 **지금 보이는 페이지만** 선택합니다.
- 한 줄의 어디를 누르는지에 따라: **채집번호·국명·학명 → 편집**, **채집지 → 지도**, **보관(박스) → 보관함**.
- **비고 · 해부 · DNA · 대여중 · 기록** 태그에 마우스를 올리면 내용이 바로 뜹니다(기다림 없는 즉시 툴팁).

## 검색 — 표본 한 건의 이력서

**검색** 탭에 번호를 넣으면(형식 무관 — `jh6` 도 `JH000006` 으로 인식) 그 표본의 모든 것이 한 화면에 나옵니다:
채집(날짜·방법·채집자), 채집지(주소·영문·라벨 약호), 보존·보관, 동정, 실험과 비고, 그리고 **계보** —
어느 tube에서 분리됐는지 / 이 표본에서 몇 개체가 분리됐는지가 링크로 이어지고, 계보 전체 개체수 합도
보여 줍니다. 오른쪽에는 채집지점 미니 지도(일반/위성 전환)와 경위도·고도가 붙고, 아래 **일지**에는
기록(대여·반납·메모) · 동정일 · 라벨 출력이 시간순으로 쌓입니다. 구번호(LJH…)·종명·채집지로도 찾아집니다.
실험한 날짜를 남기고 싶으면 ⑤기록에 메모로 적으십시오 — 일지에 날짜와 함께 나옵니다.

**종명으로 검색하면** 후보 맨 위에 **"종 전체 보기"** 가 떠서, 그 종이 몇 번 몇 번으로 몇 개체나 있는지
지점별로 나열되고 채집지 전체가 지도에 찍히며, ♂·♀ 채집기간·고도·지역 요약까지 함께 나옵니다.
번호를 누르면 그 표본의 이력서로 들어갑니다.

## 지도

**지도** 탭에서 채집지점이 좌표대로 지도 위에 찍힙니다. 오른쪽 위 버튼으로 **일반(OSM) ↔ 위성(Esri)** 을
바꿀 수 있습니다. 원이 클수록 그 지점의 개체가 많고, 원을 누르면 지점 정보와 종 구성이 팝업으로,
**지도 바로 아래에는 그 지점의 경위도·고도**가 표시됩니다. **휠 = 확대·축소, 끌기 = 이동.**

- **과 → 속 필터** — 과를 고르면 그 과의 속 목록이 채워지고, 고른 분류군을 어디에서 채집했는지만
  파란 원으로 남습니다(나머지 지점은 회색 점으로 맥락만). **전체 보기**로 초기화합니다.
- **표본목록에서 채집지를 누르면** 지도가 그 지점으로 이동해 열립니다.
- **요약** — 지도 아래에 현재 필터 기준으로 ♂·♀ 각각 몇 개체가 언제부터 언제까지(주로 몇 월에)
  잡혔는지, 고도 범위, 지역별 개체수 순위가 계산되어 나옵니다.
- 좌표가 없는 지점은 지도 밑에 이름이 나열됩니다 — 채집지점에 경도·위도를 넣으면 나타납니다.
- 인터넷이 없으면 배경지도 없이 좌표 산점도로 대체됩니다(휠·끌기는 동일).

## 실험 · 대여 기록

- **실험** — 해부(생식기 슬라이드) · DNA 추출 · 사진 촬영 체크와 비고. 목록에서 파란 태그로 보이고,
  "DNA 추출한 것 / 실험 안 한 것" 같은 필터로 거를 수 있습니다.
- **기록** — 표본별 일지입니다. 대여·반납·메모를 날짜와 함께 남기면 대여 중인 표본에
  <b>대여중</b> 표시가 붙고("대여중만" 필터 있음), 반납을 기록하면 사라집니다.

## 채집지점 — 목록이 길어지지 않는 이유

지점은 해마다 쌓이므로 드롭다운으로는 몇 해 안에 감당이 안 됩니다. 그래서 골라 쓰는 방식을 셋으로 나눴습니다.

1. **채집일을 먼저 넣으십시오.** 그날 이미 쓴 지점이 입력칸 밑에 한 줄로 깔립니다.
   하루에 여러 지점을 도는 경우가 흔하므로 **＋ 다른 지점** 도 같이 놓았습니다.
   말레이즈·핏폴처럼 기간(종료일)이 걸친 표본도 그 기간에 해당하면 함께 뜹니다.
2. **검색** — 지점 칸을 누르면 검색창이 열립니다. 지역·한글 주소·영문 표기·메모 어느 쪽이든 걸립니다.
   위·아래 화살표와 엔터로도 고를 수 있습니다.
3. **최근 사용 6곳**이 검색창 아래 먼저 뜨고, 그 밑은 **많이 쓴 순** 24곳까지만 보여 줍니다.
   지점이 15곳을 넘으면 **지역 칩**(경기 12 · 강원 8 …)이 생겨 도 단위로 먼저 좁힐 수 있습니다.

한 번에 화면에 뿌리는 것은 언제나 서른 줄 안쪽이므로 지점이 몇백 곳이 되어도 목록이 길어지지 않습니다.
검색어를 넣은 채 **＋ 새 지점 입력**을 누르면 친 내용이 한글 주소 칸으로 그대로 넘어갑니다.

## 입력을 돕는 것들

- **홈** — 검정 머리글의 **곤충 표본 관리** 를 누르면 표본목록으로 돌아가며
  검색어·필터·선택이 모두 지워지고 목록을 다시 그립니다.
- **동정 상태** — 확정 · **미동정** · 신종 후보 · 미기록 후보. 종명 없이 저장하면 자동으로
  미동정이 되고, 나중에 종을 고르면 자동으로 확정으로 돌아옵니다. 목록 필터로 "미동정만" 걸러
  숙제를 확인할 수 있습니다. 미동정은 라벨에 아무 마커도 찍지 않습니다.
- **저장·삭제 버튼은 위아래 양쪽에** — 긴 입력 화면 맨 밑에서도 저장할 수 있습니다.
- **태그에 마우스를 올리면** 내용이 보입니다 — <b>비고</b>는 동정 비고 전문, 해부·DNA·사진은 실험 비고,
  "기록 N"은 최근 기록 두 줄. 실험 태그는 색으로 구분됩니다(해부 보라 · DNA 초록 · 사진 파랑).
- **채집번호 자릿수** — 입력칸 아래에 "형식: JH + 6자리"가 항상 표시되고, `jh52`처럼 대충 쳐도
  칸을 벗어나는 순간 `JH000052`로 정형화됩니다. 빈 칸에는 다음 번호가 흐릿하게 미리 보입니다.
- **종명 검색** — 국명·학명 아무 쪽이나 두 글자만 치면 국가생물종목록에서 걸러진 후보가
  입력창 바로 아래에 나타나고, 고르면 국명·학명·목·과가 한꺼번에 채워집니다. 목록에 없으면
  "미기록종이거나 목록 미반영"이라는 안내가 뜨고 직접 입력하면 됩니다.
- **채집자 기본값** — 이재호 / JH Lee 가 미리 채워져 있습니다 (설정에서 변경).
- **고도 조회** — 채집지점에 경도·위도를 넣고 버튼을 누르면 Open-Meteo DEM(예비: Open-Elevation)에서
  고도를 받아옵니다. DEM 값이라 GPS 실측과 수 m 차이가 날 수 있고, 인터넷이 없으면 직접 입력합니다.
- **좌표는 소수점 6자리** — GPS에서 복사해 아무리 길게 붙여넣어도 저장·라벨·지도 모두 6자리로
  맞춰집니다(라벨 좌표 줄에 자동 축소도 걸어 두어 잘리지 않습니다). 지도 위에서 커서를 움직이면
  경위도가 실시간으로, 잠깐 멈추면 그 자리 고도까지 지도 아래에 표시됩니다.
- **채집지 메모** — 지점마다 서식지·접근로 같은 메모를 남길 수 있습니다.
- **번호 클릭 = 편집** — 표본목록·보관함 어디서든 채집번호(파란 글씨)를 누르면 편집으로 들어갑니다.

## 알아두면 좋은 것

- **채집지점**은 따로 등록하지 않습니다. 표본을 저장할 때 함께 등록됩니다. 한글 주소를 넣으면
  로마자 표기가 자동 생성됩니다(기존 영문 표기 11곳과 대조해 전부 일치 확인).
  지점당 한 번만 손보면 그 지점을 쓰는 모든 표본이 같은 표기를 씁니다.
- **개체 분리**는 액침 표본 편집 화면에서 누릅니다. 꺼낸 개체에 새 번호가 붙고
  `parent_no`로 원 tube와 이어지며 tube 잔량이 자동으로 줄어듭니다.
- **동정 비고**는 라벨에 찍히지 않습니다. 재검토 사항이나 다른 견해를 여기 적으십시오.
  기존 자료에서 학명 칸에 들어 있던 한글 메모 1건(구 LJH045)은 이미 이 칸으로 옮겨두었습니다.
- 저장은 **커밋**입니다. 무엇을 언제 바꿨는지가 GitHub에 영구히 남고 diff로 비교됩니다.
